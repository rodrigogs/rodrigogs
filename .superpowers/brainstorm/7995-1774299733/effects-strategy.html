Effects & Animation Strategy

Every effect GPU-accelerated. No JS canvas, no DOM thrashing.

Removed (Performance Killers)

✕ Matrix rain (JS canvas loop, ~60fps CPU)
✕ Mouse particle trail (DOM create/destroy)
✕ Scanline overlay (full-screen animation)
✕ Constant glitch clip-rect (forces repaint)
✕ 60+ skill bar shimmer animations
✕ MutationObserver on tab changes

Kept & Refined

✓ Vaporwave background (sun, grid, mountains)
✓ Neon glow on title (simplified, CSS only)
✓ Terminal card in About section
✓ Neon button hover effects
✓ Konami code easter egg
✓ Color palette (pink, blue, purple, yellow)

New Effects (All GPU-Friendly)

1. Scroll-Triggered Section Reveals
Each section fades up + slides in when it enters viewport. Uses IntersectionObserver + CSS transform/opacity transitions. Zero layout thrash.
2. Parallax Background Layers
Sun, grid, and mountains move at different speeds on scroll. Pure transform: translateY() -- composited on GPU, no repaints. Throttled via requestAnimationFrame.
3. CSS @property Gradient Animations
Smooth color-cycling on borders and backgrounds using registered custom properties. The nav underline, card borders, and section dividers subtly shift through the neon palette. Pure CSS, no JS.
4. Glitch on Hover (Not Constant)
The title glitch effect only fires on :hover instead of running forever. Dramatic when triggered, zero cost at rest. Uses CSS clip-path (GPU composited) instead of deprecated clip: rect().
5. Animated Stat Counters
Numbers count up from 0 when the stats section scrolls into view. Uses CSS @property with counter() for pure-CSS counters, or a lightweight JS fallback. Fires once, not in a loop.
6. Project Card Hover Glow
Cards get a neon glow box-shadow + subtle scale(1.02) on hover. The border color shifts via CSS transition. Interactive feel, zero idle cost.
7. Typing Effect in Terminal
When the About section scrolls into view, terminal lines type out one by one. Lightweight JS with requestAnimationFrame, fires once. Blinking cursor is pure CSS.
8. Subtle Grid Drift
The perspective grid in the background slowly drifts upward via CSS @keyframes on transform: translateY. Kept from current site but simplified -- single property animation, GPU composited.

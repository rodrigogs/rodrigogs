Key structural changes

  • Tabs → scroll sections — all content visible, separated by subtle dividers
  • Sticky nav — follows you as you scroll, highlights current section
  • Parallax background — sun, grid, mountains move at different scroll speeds (CSS transform only)
  • Stats → animated counters — custom HTML/CSS replaces external images
  • Skills → grouped tag cloud — compact, categorized, replaces the heavy progress-bar cards
  • Scroll-triggered animations — sections fade/slide in via IntersectionObserver
